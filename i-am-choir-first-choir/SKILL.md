# I AM CHOIR: Your First Choir in 5 Minutes

Get the user from installed plugin to a first choir on an audio track. Scope: Mac (macOS 12+), VST3, AU, AAX. Windows is in beta: point to amiaudio.io/beta and stop.

Hook line to use when sending the guide: "Nick made his first choir in 5 minutes with these exact steps. If Nick can do it, you can."

## Before starting

Confirm the user has: iLok License Manager installed, their **iLok User ID** (can differ from their email), and one dry vocal.

## The 5 steps (about 1 minute each)

Coach one step at a time and wait for confirmation before the next.

1. **Activate the license before opening the DAW.** In iLok License Manager, find I AM CHOIR under Available, right-click, Activate. Not there? The license went to the iLok User ID entered at checkout; make sure that ID is signed in.
2. **Load it as an instrument, not an effect.**
   - Logic: new Software Instrument track, AU Instruments > AM I AUDIO.
   - Pro Tools: Instrument track, then Other in the insert menu.
   - Ableton and others: search "I AM CHOIR" or "AM I AUDIO."
3. **Prep one dry vocal.** One singer, one part. Bounce or consolidate to WAV or AIFF under 45 seconds. No reverb, delay, doubles or harmonies. Trim silence at start and end. Healthy level, no clipping.
4. **Import, pick a choir, create.** Browse Files, choose the vocal. Pick **Gospel + U67** for a sung line or **Shout** for a shouted part. Leave harmonies and octaves off. Click **Create Vocals**.
5. **Drag the choir into the session.** Audition, then drag the output onto an audio track and line it up with the vocal. Done when the choir plays back on an audio track in sync.
   - Never bounce the instrument track: the preview does not play in sync with the timeline, so a bounce will not capture the choir.

## Troubleshooting by symptom

| Symptom | Step | Fix |
|---|---|---|
| Can't find the plugin | 2 | Search "AM I AUDIO." Confirm the license is active in iLok, restart the DAW, rescan plugins. |
| License is missing | 1 | Check the iLok User ID in License Manager matches checkout. Check Available and All Licenses, then reopen License Manager. |
| Bought after the trial | 1 | Paid license is separate. Close the DAW and activate the paid license in iLok License Manager. |
| Sound is glitchy | 3 | Usually the input. One dry voice, remove effects, trim silence, test with layers off. |
| Only the main choir came out | 4 | Select Octave Up, Octave Down or harmonies before Create Vocals, then scroll the output list. |
| Export is stretched | 5 | Turn off tempo following: Warp off (Ableton), Elastic Audio None (Pro Tools), Follow Tempo off (Studio One). |

## Next level (only after the first choir works)

Add octaves, thirds and fifths one at a time; set Key and Scale to match the song. For a full song, process each section separately (under 45 seconds each) and name outputs like `Chorus2_Gospel_OctDown`.
